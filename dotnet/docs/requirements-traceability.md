# 需求追溯

这份表回答一个问题：**`docs/03-product/01-prd.md` 里的每条 FR/NFR，在本仓库里到底落地到了哪一步？**

- 「已实现」= 有代码，且有能自动跑的用例或脚本作为证据；证据名就是 `dotnet run --project tests/Uic.Tests -- --filter <名>` 能跑到的用例名；
- 「部分实现」= 主干能用，但验收标准里有明确没做到的部分，写在备注里；
- 「刻意没做」= 有意识不做，给出原因与补法（与 [implementation-notes.md](implementation-notes.md) 的「刻意没做」一致）。

首版的目标范围是 PRD §6.1 的 Wave 1 子集：**Modbus 三封装 + S7 主站 + OPC UA 客户端 + MQTT 南向订阅 + 虚拟设备 + 四北向通道 + 配置治理 + Outbox + 可观测**。
PRD 中 M 级的采集协议已全部落地，FR-CFG-01 的四类寻址模型也按验收口径闭环
（register/symbol/file/object 都有驱动消费；object 由 BACnet/IP 核心闭环实现，
COV/分段/多属性读仍不做，见 [protocol-status.md](protocol-status.md) §4.1）。非 M 级验收里的 12 类故障注入同样全部有了
可自动跑的用例（见 §7）。

当前测试基线：**425 条**（带 `--opcua` 全量：本轮新增的一条 `bacnet/device_instance_out_of_range_is_rejected`
是纯构造、不启 UDP 服务器；全量实测数字以 [testing.md](testing.md) 最新一轮为准）。本轮新增
`bacnet/device_instance_out_of_range_is_rejected`：BACnet <MASKED_PERSON_001> deviceInstance 必须是 22 位实例号
（0..4194303），越界与非数字时由驱动明确报 Unsupported、不静默截断（-1 是「没配、不核对实例号」哨兵、被接受；
<MASKED_PERSON_001>校验器不认<MASKED_PERSON_001>私有标签，这是唯一守卫），纯构造不启 UDP、≤ 0.1 s。
此前几轮新增 `mqtt/options_reject_out_of_range_labels`（南向<MASKED_PERSON_001>数值范围与非布尔拒绝）、
`s7/label_out_of_range_is_rejected`（S7 <MASKED_PERSON_001> rack/slot/pduSize 越界）、
`s7/metadata_declares_capabilities`、`opcua/metadata_declares_capabilities`
（S7 与 OPC UA 客户端两个驱动此前无用例断言的 `DriverMeta` 能力声明钉住）。
本轮改动纯增量（新增一条纯构造用例），不改动既有用例判定，故直接复跑受影响一组确认：
`--filter bacnet/` 29 条全绿；全量汇总数字以 [testing.md](testing.md) 下一次腾空复跑所量取者为准。

## 9. 与 PRD 安全红线的差距

PRD `06-nfr.md` §4 列了五条红线，本版全部满足。TLS（FR-OPS-10）不在五条红线里，
但作为「网关直接对外」的部署前提也一并补齐：

| 红线 | 首版 | 说明 |
|---|---|---|
| 存在默认口令 | **满足**：首次启动生成 16 位随机口令，只写进 `data/security/initial-admin-password.txt`，登录后强制改密，改密成功即删除文件 | 没有 `admin/admin` 这类固定默认口令 |
| 配置文件含明文口令 | **满足**：`token`/`password` 只接受引用，明文在检查、启动与两条配置写入路径上都被拒 | — |
| 未认证即可写点位 | **满足**：账号库始终存在，未认证 401；写点位还要 `point.write` | 不再存在「不配 token = 公开」 |
| 依赖含 GPL/AGPL | 满足 | — |
| 诊断包含凭据 | 满足 | — |

安全面上没有刻意留白的项：认证（FR-OPS-02/03）、审计（FR-OPS-04）、凭据落盘
（FR-OPS-09）与 TLS（FR-OPS-10）都已在本版实现。剩下的差距是**PRD §6.1 之外的
协议范围**（Wave 2/3，见 [protocol-status.md](protocol-status.md)）与 object/file
寻址的实际驱动（模型与校验已就绪），都不是安全红线。
